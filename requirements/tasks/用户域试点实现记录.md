# 用户域试点实现记录

所属故事: ../stories/搭建共享内核与用户域试点.md

## nav-common（modules/common）

- ApiResponse（自 app 同包迁入，全仓 import 零改动）
- error/ErrorCode 接口 + error/BusinessException（支持 ErrorCode + detail 覆盖文案）

## nav-user（modules/user，四层）

- interfaces/UserController：URL/响应结构/请求头解析逻辑与原版逐项一致，Swagger 注解齐全
- application/UserService：编排事务/缓存/头像对象存储；cmd/UserCreateCmd、UserUpdateCmd、query/UserQuery、dto/UserDTO、AvatarUrlDTO
- domain/User：充血实体（updateProfile / changeAvatar 返回旧 key / checkHasAvatar）；UserErrorCode 枚举实现 ErrorCode；repository/UserRepository 接口（签名不暴露 MyBatis-Plus 类型）
- infrastructure：UserRepositoryImpl（找不到抛 BusinessException 404）、mapper/UserMapper（@Mapper）、mapstruct/UserMapstruct（componentModel=spring，User→UserDTO）、avatar/UserAvatarStore（MinIO put/get/presign/remove 封装）

## 装配改动

- 根 pom：modules + dependencyManagement 增 nav-common/nav-user/mapstruct 1.6.3
- app pom：依赖 nav-common + nav-user；GlobalExceptionHandler 增 BusinessException 处理（按 ErrorCode.status 映射 HTTP 码）
- 删除：app 的 ApiResponse/UserController；platform 的 User/UserMapper/UserService/UserCreateDTO/UserUpdateDTO/UserQuery/UserVO/AvatarUrlVO

## 模板要点（已回写 AGENTS.md）

- MapStruct 需 pom 显式 mapstruct + mapstruct-processor + lombok-mapstruct-binding 注解处理器三件套
- @Mapper 注解即被扫描；包根与主应用同根免配置
- 事务提交后清理对象（afterCommitOrNow）为 application 层职责
