# 建图切图对账闭环 V2 化实现记录

所属故事: ../stories/移植建图切图对账闭环到V2.md

## 改动清单

后端：
- MapModeStateMachine：新增 v2MapId 字段（旧构造器委托 null，v1 调用点零改动）
- MapModeTaskVO：新增 map_id_v2 出参
- MapMetaService：新增 findPublished() / getMeta(id) / createFromRobotGrid()（SOURCE_ROBOT_SYNC + 默认楼层）/ replaceRobotGrid()（栅格替换 + robotMapName 刷新 + 版本 +1）/ toGridVO()
- MapModeTaskService：
  - switchV2Map(mapId, override)：v2 切图入口；切图共通逻辑抽为 dispatchSwitchLike（v1/v2 共用）
  - publishAndFinalize：SWITCH_MAP/DISCARD_MAPPING 成功且带 v2MapId → publish（v1 navMapId 分支保留为兜底）
  - saveMap 成功自动同步链改走 syncRobotMapV2：get_map → findByUploadName 命中则 replaceRobotGrid，否则 createFromRobotGrid → 自动 publish → SSE map-sync（携带 mapId/mapName）
  - discardMapping：回退目标 v2 优先（PUBLISHED 基准 / findByUploadName），无 v2 图回落 v1
  - alignActiveMapWithRobot：v2 优先对账（机器人真实图名 ≠ PUBLISHED 基准且存在对应 v2 图 → publish 对齐 + SSE map-align），无 PUBLISHED v2 图回落 v1 对账
  - computeAlignment：v2 优先（新增 published_source 字段，state 判定对齐 MapAlignmentGuard 语义），v1 兜底
  - fetchRobotGrid 抽取复用（importRobotMap v1 入库保留，仅 v1 端点调用）
- MapV2Controller：新增 POST /api/v2/maps/{id}/switch（切图，成功自动发布）

前端：
- api/map2.ts：switchMapV2()
- MapsV2ManageDialog：非 PUBLISHED 行新增"切换"按钮（发布/切换均只对非当前使用中地图展示）
- tasks.ts onMapSync：v2 分支（mapId/mapName 提示），v1 分支保留
- types/api.ts：MapModeTaskVO.map_id_v2、MapSyncEvent.mapId/mapName

## 决策记录

- map-mode-tasks 端点（/api/v1/map-mode-tasks/*）为任务业务入口而非地图资源，保持前缀（AGENTS URL 现状条款），仅内部链路 v2 化；v2 切图独立入口 /api/v2/maps/{id}/switch
- save_map 自动同步只写 V2 表（R1）；v1 编辑器建图面板保存后不再自动加载新 v1 图（deprecated UI 可接受，列表仍刷新）
