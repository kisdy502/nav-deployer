# 搭建重构地基

状态: 测试中

## 背景与动机

DDD 全仓重构（见 ../specs/ddd-refactor.md）需要地基：规范文档入库、AGENTS.md 本地覆盖、requirements 三级目录、专用分支。同时按重构决策清除存量测试类与全仓解释性注释。

## 功能描述

1. 创建 refactor/ddd 分支
2. docs/codeStyle/ 与 DDD参考代码/ 入库
3. 编写 AGENTS.md（本地覆盖权威）
4. 建立 requirements/{specs,stories,tasks} 目录与本批 story 文件
5. 删除全部存量测试类（git 历史即归档）
6. 全仓 Java 清理解释性注释与方法 Javadoc（保留单行技术陷阱注释），前端与文档不动

## 业务规则

- R1: 注释清理仅限 modules/*/src/main/java，保留指向代码本身看不出的技术陷阱的单行注释
- R2: Swagger 注解（@Schema 等）不是注释，保留
- R3: 团队删除 team-ai-rules/ 由用户自行处理，本故事不动它

## 验收标准

- AC1: refactor/ddd 分支存在且后续工作均在其上
- AC2: AGENTS.md、requirements/specs/ddd-refactor.md、13 个 story 文件存在
- AC3: modules/*/src/test 目录全部移除
- AC4: `mvnw compile -DskipTests` 编译通过
- AC5: 主代码中不存在方法级 Javadoc 与解释性块注释（抽样检查通过）

## 范围外

- 不动前端、不动 docs/*.md、不动 DDD参考代码 与 team-ai-rules 内容

## 依赖

无
