# 新增按V2点位导航

状态: 规划中

## 背景与动机

TO_POINT（按 V1 point_id 导航）随 V1 下线消亡，但"按命名点位导航"是核心体验（前端右键"移动到点"、RMS 云端按点位派单）。需补 V2 版：to_waypoint 任务语义。

## 角色与意图

As a 机器人操作员，I want 按 V2 点位（map_waypoint）发起导航任务，So that 无需记坐标即可命令机器人去指定命名点位。

## 功能描述

move_task 支持新任务形态 to_waypoint：按 map_waypoint id 导航，后端解析点位坐标（当前 PUBLISHED 地图校验）转为坐标导航执行。前端 v2 编辑器与主页的"移动到点"改走该形态。

## 业务规则

- R1: to_waypoint 任务必须校验点位属于当前 PUBLISHED 的 V2 地图，否则拒绝
- R2: 点位坐标在任务创建时解析快照，执行中点位被改不影响已创建任务
- R3: 对外 JSON 结构沿用 move_task 现状（snake_case），新增字段向后兼容
- R4: 新端点遵循 docs/codeStyle/5-restful-api.md 与 AGENTS.md 本地覆盖

## 验收标准

- AC1: 按 v2 waypoint id 创建导航任务成功且机器人执行到达（仿真环境）
- AC2: 点位不属于当前 PUBLISHED 地图时返回业务错误码
- AC3: v2 编辑器中右键点位"移动到点"走 to_waypoint 生效
- AC4: 旧 TO_POINT 语义不受影响（在 V1 下线前共存）

## 范围外

- 路径规划优化（智能导航已有）
- RMS 云端按点位派单的协议改动（nav-rms 搬迁时处理）
