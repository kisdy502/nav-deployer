# nav-deployer frontend

机器人地图点位部署控制台（纯前端，Vue 3 + TypeScript + Three.js）。

对接部署服务器（Spring Boot，默认 `http://localhost:8083`）：地图、点位、路线（边链）、建图/切图任务、移动任务、机器人控制，实时数据走 SSE（`/sse/agv`）。

## 启动

```bash
cd frontend
npm install
npm run dev        # 代理 /api、/sse 到 http://localhost:8083（vite.config.ts 可改）
npm run dev:mock   # 后端未启动时使用内置 mock（模拟 REST + SSE + 机器人运动）
npm run build      # 类型检查 + 产物输出 dist/
```

需要 Node 18+（推荐 20+）。

## 功能

- **首页（地图管理）**：地图列表 / 保存实时图为新地图 / 重命名 / 删除 / 设为部署图 / 切换机器人地图（SSE 任务进度）/ 进入编辑器。
- **地图编辑器**：
  - 栅格地图 Three.js 渲染（占据/空闲/未知三色，origin/origin_yaw 对齐），滚轮缩放、拖拽平移、适应视图、图层显隐、坐标与比例显示；
  - 点位：列表搜索、地图点选建点、手动建点、按机器人当前位姿建点、拖动改位、旋转手柄、属性编辑（编码/类型/x/y/朝向/备注）、删除、定位、导航到此；
  - 路线（点位有序边链）：新建/选择路线后链式点击点位生成边，直线与贝塞尔曲线（1~2 控制点可拖拽）、边属性（限速/倒退/反向）、保存图形（状态回草稿）、部署/停用/删除、定位；
  - 机器人：SSE 实时位姿与轨迹、连接状态、状态栏（状态/模式/电量/地图/位姿/雷达摘要）、启动/急停/复位、重定位（地图上按下拖动设置初始位姿）、移动任务进度与取消；
  - 建图：开始建图 / 保存并入库（任务状态机 + SSE 进度）、/map 实时预览轮询；
  - 通用：右键菜单、Esc 退出模式、Delete 删除、测量工具。

## 说明

- 后端接口字段为全局 snake_case；前端类型定义见 `src/types/api.ts`，与后端 VO 一一对应。
- 服务器未配置 CORS，本地开发经 Vite 代理解决；生产部署可将 `dist/` 交给 Nginx，并把 `/api`、`/sse` 反代到 8083。
- 激光只显示摘要（后端不下发全量 ranges）；虚拟墙/区域后端暂无接口，未实现。
